# Filename Title Checker for Stash

Версия: **0.4.4**

UI-плагин для Stash, который проверяет соответствие `Title` сцены имени видеофайла, помогает находить отличия Studio, сравнивает метаданные из нескольких настроенных GraphQL/Stash-box источников и позволяет выборочно переименовывать/перемещать найденные видео.

## Как работает GraphQL-сверка

Плагин читает список источников из конфигурации Stash (`stashBoxes`). Внешние GraphQL endpoint и API-ключи не вызываются напрямую из браузера.

Для каждого выбранного источника плагин обращается к GraphQL самого Stash и использует `scrapeSingleScene` с `stash_box_endpoint` и `scene_id`. Stash выполняет поиск по fingerprints файлов сцены и возвращает найденные метаданные.

Это позволяет сравнить, например:

- текущие данные Scene в Stash;
- результат StashDB;
- результат TPDB/Stash-box;
- другой совместимый Stash-box источник, уже настроенный в Stash.

Если источник не находит сцену по fingerprints, под ним выводится сообщение **«Совпадений по fingerprints не найдено»**.

### Сохранённые данные

Кнопка **«Сохранить в Scene и использовать»** применяет выбранный вариант к Scene через GraphQL `sceneUpdate` и дополнительно сохраняет компактную копию в `localStorage` браузера. Для конкретной Scene запоминаются в том числе:

- Title;
- Studio;
- Date;
- Performers;
- источник и remote ID;
- дополнительные поля результата.

При построении целевого имени и папки плагин использует сохранённые `Title`, `Studio`, `Date` и `Performers` вместо текущих значений Scene.

Начиная с v0.3.3 база Stash обновляется. Локальная копия используется только как резерв для немедленного расчёта имени файла; после автоматической перепроверки используются уже сохранённые данные самой Scene.

## Шаблон переименования

Основной шаблон перенесён из приложенного `renamer-dev`:

`Date - Studio - Title - [WEBDL-Height].ext`

Пример:

`2026-08-21 - SexArt - Beside You - [WEBDL-1080p].mp4`

Если для Scene выбран результат GraphQL, в шаблон подставляются сохранённые значения GraphQL. Если сохранённого результата нет — используются текущие данные Scene в Stash.

Правила:

- используется `Scene.date` или сохранённая GraphQL Date;
- используется `Scene.studio.name` или сохранённая GraphQL Studio;
- используется `Scene.title` или сохранённый GraphQL Title;
- высота берётся из выбранного `VideoFile.height`;
- расширение исходного видео сохраняется;
- недопустимые для имени файла символы `< > : " / \\ | ? *` заменяются на `-`;
- отсутствующие поля пропускаются.

### Специальный шаблон из renamer-dev

Для Studio `1By-Day111` сохранено правило:

`Studio - Date - Performers - Title`

Исполнители сортируются по имени, максимум 3, как в приложенном `renamer-dev`. Если выбран GraphQL-вариант, могут использоваться сохранённые Performers.

## Перемещение

Обычная сцена переносится в:

`<текущий Stash Library Path>/<Studio>/`

Если сохранённый GraphQL-вариант содержит другую Studio, целевая папка рассчитывается уже по этой Studio.

Например:

Текущая Studio в Stash: `Wrong Studio`

Сохранённый GraphQL-вариант: `SexArt`

Целевой путь:

`<Library Path>\SexArt\Date - SexArt - Title - [WEBDL-1080p].mp4`

Если Studio отсутствует, используется папка `No Studio`.

### Специальный путь Movie

Сохраняется правило из `renamer-dev`:

`Movie -> E:\Movies\<Studio>\`

Операция разрешается только если путь находится внутри одного из Stash Library Paths.

## Как выполняется переименование

Плагин использует штатную GraphQL mutation Stash `moveFiles` и передаёт для каждого выбранного видео:

- ID видеофайла;
- `destination_folder`;
- `destination_basename`.

Перед запуском отображается рассчитанный будущий путь. Файлы обрабатываются по одному; ошибка одного файла не останавливает остальные.

## Связанные файлы

Версия 0.3.2 **не перемещает автоматически** `.srt`, `.vtt`, `.jpg` и `.png`. Обрабатывается только явно выбранный видеофайл.

## Выбор файлов

Чекбокс активен, если:

- у строки есть видеофайл;
- после применения сохранённых данных есть `Title`;
- можно определить расширение;
- файл находится внутри одного из настроенных Stash Library Paths;
- специальный путь для `Movie`, если он нужен, находится внутри одного из Stash Library Paths.

## Правила сравнения Title

Сохраняются правила v0.1.5:

- расширение файла отбрасывается;
- регистр игнорируется;
- пунктуация считается разделителем;
- `&` и `and` эквивалентны;
- апострофы игнорируются;
- диакритика игнорируется (`Qué` = `Que`);
- границы между буквами и цифрами разделяются (`DAY2026` = `Day 2026`);
- сравнение выполняется по последовательности целых слов;
- специальных fuzzy/Levenshtein-правил нет.

Поэтому остаются несовпадениями:

- `Asphyxxia` ≠ `Asphyxia`;
- `Angels` ≠ `Angles`;
- `Gina Valentina` ≠ `Gina Valentine`;
- `Step Daughter` ≠ `StepDaughter`;
- `De Ville` ≠ `DeVille`.

## Фильтры Studio

**Только в пределах той же студии** — показывает несовпадения Title, у которых Studio в имени файла совпадает с текущей `Scene.studio`. При сравнении Studio игнорируются регистр и пробелы, поэтому, например, `AcademyPOV` и `Academy POV` считаются одной студией.

**Только с разными студиями** — показывает несовпадения Title, у которых Studio в имени файла действительно отличается от текущей `Scene.studio` после нормализации регистра и пробелов.

Фильтры взаимоисключающие.

## Переход по страницам

Между кнопками **«← Назад»** и **«Вперёд →»** есть выпадающий список для прямого перехода на конкретную страницу.

## Установка / обновление

1. Распакуйте ZIP.
2. Замените файлы Filename Title Checker в каталоге `plugins` Stash:
   - `filename-title-checker.yml`
   - `filename-title-checker.js`
   - `filename-title-checker.css`
3. В Stash откройте **Settings → Plugins**.
4. Выполните **Reload Plugins**.
5. Обновите страницу браузера.
6. Откройте **Filename Check**.

## Важно о сохранении GraphQL-результатов

Выбранные предпочтительные данные сейчас хранятся в `localStorage` браузера. Поэтому:

- они сохраняются после перезагрузки страницы;
- не требуют изменения конфигурации или базы Stash;
- относятся к конкретному браузеру/профилю;
- очистка данных сайта/Local Storage удалит сохранённые варианты.

В будущей версии при необходимости это можно перенести в постоянное хранилище Stash/плагина.

## Безопасность

- API-ключи Stash-box остаются в конфигурации Stash;
- внешние источники вызываются через backend Stash;
- выбор GraphQL-результата сам по себе не меняет Scene;
- фактическое переименование выполняется только после отдельного выбора чекбоксом и подтверждения;
- физическое перемещение выполняет Stash через `moveFiles`.
